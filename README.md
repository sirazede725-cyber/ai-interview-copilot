# 通用 AI 面试助手

这是一个本地运行的通用面试回答工具。它根据结构化简历、项目深挖资料、岗位技术知识和 AI 前沿知识，为当前问题生成有事实依据的口述回答。

> 本项目用于获得面试方明确允许的 AI 辅助场景及日常面试训练。使用者应遵守具体招聘流程的考试和面试规则。

- **面试模式**：支持手动输入或中文语音识别，只显示问题、完整回答和2—3个可能追问。语音默认按“一问一停”工作，避免把候选人的回答再次识别成新问题。
- **备战模式**：查看个人事实、项目深挖、Python、RAG、Agent、安全评测、模型部署和 AI 前沿知识，并可直接选择主题测试。
- **回答流程**：语音转写/文本输入 → 识别问题意图 → 检索个人事实、技术知识与论文卡片 → 模型组织回答 → 输出可能追问。
- **论文知识**：已加入DynTrust与BF4Hg两篇论文的方法、实验、局限和表述边界；论文原文不发送给前端，只向模型提供本题命中的少量卡片。
- **岗位定向层**：当前加入Python后端岗位画像，覆盖FastAPI、PostgreSQL、Redis、数据抽取、从零到一交付和AI辅助编程质量控制；岗位通用知识与个人真实经历分开存储。
- **事实边界**：个人经历和通用知识严格分开，避免把技术理解包装成亲身经历。

## 启动

在本目录运行 `python app.py`，然后打开 `http://127.0.0.1:8765`。

后端默认读取 `.env.local` 中的 OpenAI Chat Completions 兼容配置。当前推荐使用 `deepseek-flash` 的非思考模式，以兼顾回答速度、效果和调用成本。`.env.local` 已加入忽略规则，不应提交到代码仓库。页面右上角“设置”可在当前浏览器标签页临时覆盖后端配置。

知识库未包含手机号、邮箱、微信号或小程序登录信息。不要把面试录音或私人配置提交到代码仓库。

## 测试

```powershell
python -m unittest discover -s tests -v
```

测试覆盖意图识别、简历事实检索、岗位知识检索、论文卡片召回、离线降级和公司中立性。项目仅使用 Python 标准库，未配置 API 时仍可演示检索与离线回答提纲。

## 隐私与安全

- API Key 仅从本机 `.env.local` 或临时页面设置读取，不进入 Git。
- 仓库不保存真实面试录音、手机号、邮箱或登录凭证。
- 个人事实与通用技术知识分层保存，回答提示要求模型不得虚构项目经历。
